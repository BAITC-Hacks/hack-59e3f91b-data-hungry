# Frontend: chat widget for ekt.kz

## Решения
- **Один файл `widget/widget.js`, без сборки.** Vanilla JS + CSS-строка внутри. Подключается одним тегом `<script>` на любую страницу (в т.ч. Bitrix-сайт ekt.kz, где уже есть jQuery/Bootstrap 5).
- **Shadow DOM.** Весь UI живёт в `host.attachShadow({mode:'open'})`, поэтому стили сайта не ломают виджет, а виджет не ломает сайт. Это и есть «совместимость с текущей платформой».
- **Состояние:** `session_id` в `localStorage['ekt_ai_session']`, история сообщений в памяти (+ `sessionStorage`, чтобы пережить переход между страницами сайта), `pending_action`, `cart`.
- **Язык:** переключатель RU / KZ в шапке, отправляется как `lang` в `/api/chat`; ответы приходят на выбранном языке.
- **Без стриминга в v1:** индикатор «печатает…», ответ приходит целиком за несколько секунд.
- Cart page рендерит бэкенд (`GET /cart/{session_id}`), фронт только ссылается на неё. На ekt.kz — режим «родной корзины» (см. контракт).

## Структура папки
```
widget/
  widget.js          # весь виджет (стили + логика + API-клиент)
  demo/index.html    # имитация карточки товара ekt.kz + <script src="../widget.js" data-api="http://localhost:8000">
  bookmarklet.js     # javascript:(()=>{const s=document.createElement('script');s.src='https://HOST/widget/widget.js';s.dataset.api='https://HOST';document.body.appendChild(s)})()
  README.md          # как подключить, параметры data-*
```
Параметры тега: `data-api` (базовый URL бэкенда), `data-lang` (`ru`|`kk`, по умолчанию `ru`), `data-open` (`1` — открыть панель сразу), `data-title` (заголовок).

- **Кнопка-лаунчер:** круглая 56px справа снизу, бейдж с количеством в корзине. На мобилке панель на весь экран (`100dvh`, `env(safe-area-inset-*)`), инпут `font-size:16px` (чтобы iOS не зумил).
- **Десктоп:** панель 400×640, `position:fixed; right:24px; bottom:96px; border-radius:16px; box-shadow`.
- **Состояния запроса:** `sending` (индикатор «печатает…», кнопка disabled), `error` (красная плашка «Не удалось отправить, повторить»), таймаут 60 с.
- **Клавиатура:** Esc закрывает панель, фокус в инпут при открытии, `aria-live="polite"` на списке сообщений.
- **Markdown:** свой мини-рендер (bold, курсив, списки, ссылки, переносы) + экранирование HTML. Никакого `innerHTML` с сырым текстом от API без экранирования.

## Поток «добавить в корзину»
1. Пользователь пишет «добавь 2 шт» или жмёт «Добавить в корзину» на карточке → `/api/chat`.
2. Бэкенд отвечает `pending_action` → виджет рисует блок подтверждения (корзина НЕ изменена).
3. «Подтвердить» → `POST /api/chat/confirm {confirm:true}` → ответ с `cart_updated:true` и новой `cart` → cart bar обновляется, в чате появляется ссылка на корзину.
4. «Отмена» → `confirm:false` → блок исчезает, корзина не тронута.
5. На `ekt.kz` (hostname заканчивается на `ekt.kz`): после шага 3 дополнительно POST в `/local/templates/template/ajax/basket.php` для каждой позиции и ссылка `https://ekt.kz/personal/cart/`.

## Вложения
- Кнопка 📎 → `<input type=file accept=".jpg,.jpeg,.png,.webp,.xlsx,.xls,.docx,.pdf">` → `POST /api/upload` → chip с `summary`.
- При отправке сообщения `attachment_ids` уходят вместе с текстом; если текст пустой, отправить «Посмотри вложение».

## Demo page (`widget/demo/index.html`)
Имитация карточки товара ekt.kz: шапка «ЭлектроКомплект», хлебные крошки, фото, название `027228 АВ DRX250 MT 3ф 160А 18ka Legrand`, цена, кнопка «В корзину» (нерабочая, просто визуал), характеристики. Внизу подключён виджет с `data-api`. Нужна для показа на десктопе и в мобильном эмуляторе DevTools.

## Что показать жюри (сценарий демо)
1. «Есть ли 027228 Legrand в наличии?» → карточка с остатком по складам, характеристиками и сертификатом.
2. «А если нет — что взамен?» на товаре с нулём (например `***LED STARK 30W`, id 45357) → 2–3 аналога с обоснованием.
3. «Какие условия доставки в Астану и как оплатить юр. лицу?» → ответ из базы знаний.
4. «Добавь 2 штуки» → блок подтверждения → «Подтвердить» → ссылка на корзину → открыть страницу корзины.
5. Загрузить Excel-спецификацию → ассистент находит позиции, показывает наличие, предлагает добавить всё разом.
6. Переключить KZ → тот же вопрос на казахском.
7. (Если успеем) Букмарклет на живом ekt.kz → товар попадает в настоящую корзину сайта.
