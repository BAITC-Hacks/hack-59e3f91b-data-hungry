# GPU VM для хакатона

Подключение с машины, где уже настроен SSH-алиас:

```bash
ssh distinctive-orange-mammal
```

Быстрая проверка перед запуском GPU-задач:

```bash
ssh distinctive-orange-mammal 'hostname; nvidia-smi'
```

Проверка, предоставленная командой 23.09.2026, вернула hostname `brev-uct8xo9mo` и одну NVIDIA H200: 143771 MiB видеопамяти, драйвер `580.173.02`, CUDA `13.0`, MIG отключён. В момент проверки GPU-процессы отсутствовали. Это снимок состояния, а не гарантия неизменности конфигурации; перед каждым запуском проверяйте `nvidia-smi` заново.

`distinctive-orange-mammal` — локальный SSH-алиас. Ключи, токены и содержимое SSH-конфига в репозиторий не добавлять. Хост и порт, показанные SSH при подключении, могут измениться при пересоздании VM.

Скрипт [`deploy/push_to_vm.sh`](../deploy/push_to_vm.sh) использует этот алиас по умолчанию; при необходимости его можно заменить через `VM_HOST`. Перед первым запуском скрипта убедитесь, что его целевой каталог `~/ekt-assistant` действительно выделен под этот проект: синхронизация использует `rsync --delete`. Базы каталога и вложений, загрузки, дампы, локальный `.env` и лог сервера исключены из удаления.
