# Сценарий демо для жюри (5–7 минут)

**Стенд:** https://ekt-assistant-ypmkr1h7l.gobrev.dev/widget/demo/index.html (имитация карточки товара ekt.kz, виджет открыт сразу).
Health: https://ekt-assistant-ypmkr1h7l.gobrev.dev/api/health. Мобильная версия: открыть тот же адрес на телефоне или в DevTools (панель на весь экран).

Сайт ekt.kz сейчас отвечает по 7–9 секунд на первую карточку товара, дальше работает кеш. Перед демо стоит один раз прогнать пункты 1–2, чтобы карточки были прогреты.

| # | Критерий кейса | Что написать в чат | Что покажет |
|---|---|---|---|
| 1 | Наличие, характеристики, сертификат по артикулу | `Есть ли в наличии 027228 Legrand? Нужны характеристики и сертификат` | Карточка: 23 шт с разбивкой по складам, цена, полюса/ток/отключающая способность, ссылка на сертификат |
| 2 | Аналоги при нулевом остатке | `Есть ли дифавтомат 007886 Legrand 411002? Если нет — что взамен?` | «Нет на складе» + 2 аналога IEK с обоснованием: тот же тип, 16 А, 30 мА, бренд, разница в цене |
| 3 | Условия покупки | `Какие условия доставки в Астану и как оплатить юр. лицу? Есть минимальная партия?` | Пороги бесплатной доставки (30 000 ₸ по городу, 400 000 ₸ по РК), оплата по счёту, кратность упаковки |
| 4 | Корзина только после подтверждения, не больше остатка | `Добавь 2 штуки 027228 в корзину` → жёлтый блок «Подтвердить / Отмена», корзина пуста → `да, добавь` (или кнопка) | Корзина: 2 шт, ссылка «Открыть корзину». Затем `добавь ещё 9999 штук` → ассистент ограничивает 21 шт по остатку |
| 5 | Ссылка на корзину | Нажать «Открыть корзину» | Страница корзины с актуальным составом и кнопкой «Оформить заказ на ekt.kz» |
| 6 | Вложения (Excel-спецификация) | Скрепка → `docs/demo/spec_demo.xlsx` → `Проверь наличие по спецификации и предложи добавить всё, что есть` | Таблица по 4 позициям, аналог для отсутствующей, одно предложение на 3 позиции в наличии → «Подтвердить» |
| 7 | Казахский язык | Переключить KZ → `027228 қоймада бар ма? Бағасы қанша?` | Ответ на казахском с остатком и ценой |
| 8 | Эскалация | Кнопка «Менеджер» или `Нужна спецификация на 200 позиций со скидкой` | Контакты менеджера (телефон, WhatsApp, e-mail) |

**Что подчеркнуть:** цена и остаток всегда из API ekt.kz (инструменты, не память модели); корзина меняется только сервером после явного «да» и с проверкой остатка и кратности; виджет — один `<script>` с Shadow DOM, на самом ekt.kz кладёт товар в родную корзину Bitrix; сертификаты — синтетический демо-реестр, потому что API их не отдаёт (структура готова под реальные документы).
